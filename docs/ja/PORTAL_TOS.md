# GANSU2 ユーザーポータル — アカウント利用規約

**発効日:** 2026-09-14

本規約は、GANSU2 ユーザーポータル <https://gansu2.github.io/portal/> を通じて作成される
GANSU2 ユーザーアカウント（「**アカウント**」）と、そのアカウントに紐づくすべての
GANSU2 ライセンスキーの利用に適用されます。本規約は、ソフトウェアのすべての利用に適用される
[GANSU2 利用規約]({{ '/ja/TERMS/' | relative_url }})を補完するものです。

## 1. 同意
アカウントを作成し、またはアカウントの下で発行されたライセンスキーを有効化することにより、
本規約に同意したものとみなされます。同意されない場合はアカウントを作成しないでください。

## 2. アカウント
GANSU2 ユーザーアカウントは、ライセンスキーを利用者に帰属させるための個人の識別情報です。
作成時に **無料ライセンス（Free License）** が 1 つ自動で付与され、ポータルのダッシュボードから
開始します。当方は裁量により追加のライセンスをアカウントに付与することがあります。
種類を問わずすべてのライセンスは、発行時に伝達される個別条件に加えて本規約に従います。

## 3. ライセンスの許諾
アカウントに紐づく各ライセンスについて、当方は、ポータルのダッシュボードに表示される期間・
**Max Size** 上限・その他の条件の範囲で、GANSU2 を利用する限定的・非独占的・譲渡不可・
撤回可能なライセンスを付与します。

**無料ライセンスは、商用を含むあらゆる用途での GANSU2 の利用を許諾します。** 評価・研究・
非商用目的への限定はありません。他の種類のライセンスは、発行時または別途の合意で定める
異なる条件を伴うことがあります。

## 4. 個人につき 1 アカウント
各個人が同時に保有・運用できる GANSU2 ユーザーアカウントは **1 つのみ** です。以下は禁止します。

- 追加ライセンスの取得やアカウント単位の制限の回避を目的として、メールエイリアス・別アドレス・
  同僚や親族名義などで複数のアカウントを作成・運用すること。
- アカウントの認証情報を他者と共有し、またはアカウントを他者に譲渡すること。

本条項に違反すると当方が合理的に判断したアカウントは、停止または閉鎖し、
紐づくライセンスを取り消すことがあります。

## 5. 制限事項
以下を行ってはなりません。

- GANSU2 のバイナリ・ライブラリ・ライセンスキーの再配布またはサブライセンス。
- バイナリのリバースエンジニアリング・逆コンパイル、ソースコードの導出の試み。
- 有効化・マシン紐付け・検証・レート制限の各機構の回避（無効化のクールダウンや更新期間の
  回避を含むがこれに限られない）。

## 6. 収集する情報
アカウント作成時に、メールアドレス・氏名・所属・役割・国・利用目的を収集します。

ライセンスの有効化または検証時に、実行環境に関する技術情報を収集します。これには例えば、
マシンフィンガープリント、ホスト名、OS ユーザー名、OS、CPU / GPU 情報、RAM 容量、IP アドレス、
実行環境のバージョン情報（GANSU2 ソフトウェア、実行フロントエンド（C++ または Python、
該当時は Python バージョン）、システム C ライブラリ（glibc）、GPU ドライバなど）が含まれます。
これらはライセンス管理と、旧バージョンのサポート終了時期の判断など互換性・サポートの判断のためにのみ利用します。

以下は**収集も送信もしません**。

- 利用者のプログラムのソースコードやコンパイル済みバイナリ
- 利用者が扱う分子座標・基底関数系その他の入力データ
- 利用者が設定した計算の内容（手法・パラメータ等）
- 計算結果、エネルギー、波動関数その他の出力
- 利用者のファイルの内容やパス

ライセンス検証メッセージには、本節冒頭に記載した技術メタデータのみが含まれます。

ユーザーポータルを通じてライセンスに任意で付与した自由記述のメモは、そのライセンスとともに
保存され、GANSU2 管理者から参照できます。機微な個人情報・秘密・第三者の機密情報を
メモに入力しないでください。

サインアップ情報（メール・氏名・所属・役割・国・利用目的）を記録し、GANSU2 および関連
ソフトウェアの情報提供のため、当方の共同研究者へ開示することがあります。ライセンス検証の
メタデータ（マシンフィンガープリント、IP、ハードウェア仕様等）はこの目的では開示しません。

当方への連絡（GANSU2 のウェブサイトに示す連絡先）により、いつでもこうした開示を停止できます。
停止は既存ライセンスの動作に影響しません。

GANSU2 は **現状有姿（"AS IS"）** で提供され、商品性・特定目的適合性・権利非侵害を含む
いかなる明示または黙示の保証も伴いません。

## 8. 終了
当方は、理由の有無を問わず、また事前通知なく、**いつでも**ライセンスを停止・取消し、または
アカウントを閉鎖することがあります。利用者はいつでもユーザーポータルからアカウントを削除でき、
その場合アカウントに紐づくすべてのライセンスは停止されます。

## 9. 本規約の変更
当方は本規約を随時改定することがあります。重要な変更はメールまたはポータルの通知で連絡します。
